# Skills

Reusable instruction folders any agent can load when a task needs them. AGENTS.md says when.
Claude Code finds them through the `.claude/skills` link to this folder.

| Skill | Use when | Source | License |
| --- | --- | --- | --- |
| `stop-slop/` | Writing or reviewing any text a person reads: UI copy, docs, pull requests, commits | [hardikpandya/stop-slop](https://github.com/hardikpandya/stop-slop) @ `8da1f03` | MIT, copied verbatim |
| `nielsen-heuristics-audit/` | Reviewing a screen or a screenshot for usability | [mastepanoski/claude-skills](https://github.com/mastepanoski/claude-skills) `skills/nielsen-heuristics-audit` @ `ac30238` | MIT, copied verbatim |

Further reading, not copied (no license): [realrossmanngroup/no_ai_slop_writing_rules](https://github.com/realrossmanngroup/no_ai_slop_writing_rules).

To update a skill, copy the folder again from its source and change the commit in this table.
